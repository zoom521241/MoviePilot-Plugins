# 115文档订阅与查询 — Doc115Subscribe

> 从**腾讯文档**追更表读取资源：定时为**电影订阅**转存到 115 网盘，并支持插件内跨表**搜索转存**。

**作者：** zoom521241

---

## 背景：文档不能下载，但能读

目标文档（腾讯文档在线表格）**关闭了下载/导出**，且表格是 **canvas 渲染**（DOM 里拿不到单元格）。
本插件做法：调用**文档前端自身的 dop-api 接口**取单元格数据块
（`related_sheet` = base64(zlib(protobuf))）再解码，因此：

- ✅ 不需要「导出/下载」权限
- ✅ 不需要浏览器
- ✅ 只依赖 Python 标准库

> 接口属前端内部接口，腾讯改版可能失效；解析逻辑已独立成模块便于维护。

---

## 功能

### 1. 订阅下载（仅电影）
每天定时读取文档「最新电影（持续更新）」表：

- 与 **MP 订阅列表**比对（优先用表内 **TMDBID** 精确匹配，缺失时用「片名+年份」）；
- 命中后转存到 115 网盘电影下载目录，交由 MP 整理 / STRM 入库；
- **电视剧不参与订阅**（按需求）。

### 2. 查找（电影 + 电视剧）
插件内搜索框输入片名 → 在**所有工作表**中模糊搜索 → 展示结果并标注**电影 / 电视剧**
→ 选中后一键转存，**可手动指定**电影或电视剧目录（防止类型误判）。

### 3. 链接类型自动分派

| 链接形态 | 处理方式 |
|---|---|
| `115.com/s/…`、`115cdn.com/s/…`（含 `?password=`） | **115 转存**（share_receive） |
| `magnet:?xt=urn:btih:…` | **115 离线下载** |
| `ed2k://…` | **115 离线下载** |
| 其他 http（如 themoviedb 页面） | 忽略，不作为资源链接 |

### 4. 选片规则
同一条目有多条资源时：**`4K+中文` > `4K` > `中文` > 其他**；都不满足取**最新（最上）一条**。

### 5. 其他
- 文档地址可配置，避免文档地址变更后改代码；
- 115 Cookie 留空时按顺序复用其它 115 插件已保存的 Cookie：115网盘STRM助手 → 115网盘储存 → 115网盘订阅追更；
- **本地索引**：每天刷新一次并缓存，搜索走缓存（文档 90 张表，实时全量抓取过慢）。

## 配置

| 字段 | 说明 |
|---|---|
| 启用插件 | |
| 腾讯文档链接 | 默认已填 |
| 腾讯文档 Cookie | 登录 docs.qq.com 后复制；**仅本地保存，日志脱敏** |
| 115 Cookie | 留空则自动复用其它 115 插件（STRM助手 → 网盘储存 → 订阅追更） |
| 115 电影下载目录 | 默认 `/115-影视/115-downloads/电影` |
| 115 电视剧下载目录 | 默认 `/115-影视/115-downloads/电视剧` |
| 索引刷新 cron | 默认 `0 6 * * *`（每天 6:00） |
| 订阅同步 cron | 默认 `0 21 * * *`（每天 21:00） |

## 目录结构

```
doc115subscribe/
├── __init__.py      # 插件主体：配置 / 定时 / API / 页面
├── doc_client.py    # 腾讯文档读取（dop-api + protobuf 解码，含超链接提取）

├── link_router.py   # 链接类型识别与分派
└── pyproject.toml
```
