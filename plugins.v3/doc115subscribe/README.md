# 115文档订阅与查询 · Doc115Subscribe 0.10.0

读取腾讯文档追更表建立本地索引，提供跨表搜索、手动获取和 MP 活动电影订阅匹配。电视剧支持搜索、手动获取。插件的获取、搬运和 MP 整理状态分别显示，获取成功不会被后续整理失败覆盖。

## 页面与使用

- **搜索**：名称、电影/电视剧、画质、字幕、来源独立筛选，服务端分页。结果绑定记录 ID 和索引版本；刷新索引后重新搜索。蓝光/REMUX 不直接当作 4K。
- **手动获取**：确认实际来源，再选电影或电视剧下载目录；目录选择与媒体身份分开，MP 仍按自身识别结果整理。提交按钮仅排队，后台执行云端请求。
- **电影订阅**：只处理 MP 活动电影订阅，优先 TMDB ID，严格核对年份和完整标题。预演复用实际规则评估，只读缓存，不提交资源。外部过滤组无法可靠评估时明确阻止自动获取。
- **任务**：分页查看获取与整理状态、逐文件证据、待核实项和可执行动作。刷新列表、诊断、预演均不直接请求 115。浏览器隐藏或离页后停止轮询。
- **设置**：腾讯文档微信扫码或手填 Cookie；115 Cookie 留空可复用已支持插件配置。凭据不回显，空输入保留，清除需明确选择。MP 下载目录建议来自后台缓存，未确认监控时保留明确提示与手填路径。

字段颜色由插件自己的 CSS 控制，不依赖 MP/Vuetify 的材质色工具类；明暗主题和小屏显示均有独立样式。

## 获取与 MP 整理

| 来源 | 插件行为 |
|---|---|
| 115 分享 | 分段读取原始必要文件清单，再按顶层项目分批转存到最终下载目录 |
| 磁力 / ed2k | 离线到暂存目录，核对原任务哈希、文件 ID 和父目录，再调用 115网盘Plus 搬运整包 |
| 网页链接 | 可查看，不提交下载 |

默认 `first` 将多个链接视为镜像，仅在明确获取失败后尝试备用来源。不确定提交、风控、鉴权失败或预算延期不会触发备用下载。明确属于多个必要资源时才选 `all`；相同分享码和相同离线哈希不会因 URL 别名重复提交。

下载任务被 115 接受、下载 100%、文件落盘、搬入下载目录、MP 整理成功是不同阶段。磁力提交和分享转存通常很快，但离线完成受 115 资源与下载速度影响；清单扫描、目录核实和请求预算可能延后搬运。插件不承诺几秒内完成整季整理。

插件仅复用 115网盘Plus 的受控私有客户端执行搬运，不修改 Plus 或 MP 程序。后续整理、STRM、媒体库扫描依赖你的 MP/115 插件监控配置。本插件不根据文件消失或同名历史猜测入库，只关联本批次的源路径、存储、文件身份、媒体信息和时间证据。

**20 集中仅 19 集有整理成功证据，会显示 19/20、部分完成和 1 项待核实，不会误报全部入库，也不会自动重新获取整季。** 原始清单保留，即使整理前人为删除一集也不会把预期缩成 19 集。明确整包搬运回执结合本批次 MP 下载目录证据可以确认搬运；这不改变整理缺集状态。

磁力整包在首次扫描前已被删除文件、且没有可信原始集数时，无法从剩余文件推断全集。此时显示完整性未证实，全部已扫描文件整理成功也不宣称整季完整成功。电影单文件不受这一整季限制。

MP 事件只进入本插件有界队列，不执行云端请求。历史核对合并相同标题与分页查询，保留游标，失败退避；24 小时仍未确认的整理任务停止自动核对，可人工恢复原任务核对。

## 附带小视频

默认将已知体积小于 10 MB（按 1024² 字节换算）的普通视频标为附带文件，不计入必要整理数；可以在设置中调整为 0 到 1024 MB，0 关闭。你删除这些小视频不会让主要资源误报缺失。大小未知或异常的文件继续保留为必要文件；蓝光 m2ts/ISO 不按此规则忽略。附带文件在任务详情仍可查看，插件不删除云端文件，也不修改 MP 自己的过滤规则。全部都是附带小视频时不会虚报主要资源全部整理成功。

每个任务保存创建时的阈值，修改设置仅影响新任务；已有原始清单不会随配置变化而缩小。正规的单集被删除仍按原清单提示缺集。

## 风控、恢复和边界

- 115 同账号请求并发为 1，真实 HTTP 请求间隔至少 2 秒，滚动每分钟最多 20 次、新提交最多 3 次；工作切片最多 5 请求 / 15 秒。SDK 和 Plus 内部请求同样计数，不自动重试或跟随重定向。
- 预算与账号冷却持久化，重载不清零；状态损坏或写盘失败会暂停云端操作。115 鉴权、限流和风控响应触发冷却。
- MP 只读访问并发 1、每分钟最多 20 次、切片最多 5 次；认证与错误响应共享退避，不反复扫端口。没有待核对项、目录读取请求或订阅任务时不读取 MP 业务接口。
- 私有 SQLite 账本先登记写意图、再保存回执。重启、停用或换配置期间的在途回执仍保留；旧代次不能继续安排任务。换 115 账号后原账号任务暂停。
- 分享提交响应不明时停止自动重发，需在 115 原生界面人工核实。离线失败后的检查仅核对原任务，不重新下载。重试获取仅允许明确失败且不存在成功或未确认写入的任务。
- 删除或清空任务展示只隐藏记录，防重复证据和后台任务保留；停止跟踪不取消 115 下载，也不删除文件。整理失败后的核对不会重新转存。
- 新安装自动电影订阅默认关闭；升级保留已有配置。获取更高版本默认关闭，开启后仅尝试高于已完成质量的资源。

| 插件启用 / 电影订阅 / 更高版本 | 关闭 / 关闭 / 关闭 |

最终下载目录必须由你的 MP/115 整理流程正确监控。目录缓存只反映配置快照，不代表监控实际运行或媒体库已扫描。

## 升级与依赖

升级前备份本插件配置与私有数据。旧历史和待搬运 JSON 自动迁移到 SQLite，原文件保留；迁移失败会明确阻止不受保护的新任务。旧索引来源无法验证时作废，需要重新刷新文档索引。

运行需 MP V3 / Python 3.12 及以上，并已有兼容的 115网盘Plus SDK。插件 `pyproject.toml` 不安装或替换宿主共享 SDK；缺少兼容能力时仅暂停云端获取和搬运，文档搜索仍可用。微信扫码另需已有 Playwright/Chromium，缺失时可手填腾讯文档 Cookie。

## 模拟验证与前端构建

测试使用合成文档、虚构资源、假 HTTP、真实 FastAPI/调度框架和隔离账本，不需要生产凭据，禁止真实转存、离线、搬运和整理。覆盖成功、明确失败、响应丢失、分页预算、重复提交恢复、并发串片、重启/停用、账号切换、删除一集、MP 立即移走原目录、过滤预演与原生权限。外部服务和宿主契约仍可能变化，模拟通过不等于所有环境零缺陷。
