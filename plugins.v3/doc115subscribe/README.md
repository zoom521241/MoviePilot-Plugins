# 115文档订阅与查询 · Doc115Subscribe 0.8.0

读取你有权访问的腾讯文档在线表格，建立本地资源索引；支持电影订阅同步，以及电影、电视剧的跨表搜索和手动转存。文档读取通过前端数据接口完成，不依赖导出权限；微信扫码登录另需浏览器运行环境。

## 功能与处理规则

- **跨表搜索**：在完整本地索引中按名称、电影/电视剧、4K/中文字幕筛选，再分页返回。蓝光、REMUX 本身不等于 4K。每条结果绑定资源 ID 和索引版本；刷新索引后必须重新搜索，避免旧结果转存成其它资源。
- **电影订阅**：读取 MoviePilot 的活动电影订阅。优先匹配 TMDB ID；双方明确存在的 ID、年份或媒体类型冲突时排除。身份缺失时才按完整片名兜底，不把续集或任意标题前缀当成本片。电视剧支持搜索和手动转存，不参与自动订阅。
- **候选选择**：只考虑独立且可转存的资源，按身份匹配、`4K+中文 > 4K > 中文 > 其它` 排序；确定失败时尝试其它候选。整表打包、共用大包链接、纯列表只展示链接，禁止一键转存。
- **订阅过滤**：根据文档文字检查订阅的 `include`、`exclude`、`quality`、`resolution`、`effect` 条件。文档无法可靠评估 MoviePilot 外部规则 `filter` 或 `filter_groups` 时，会阻止该订阅自动下载并显示原因；不会宣称完整复用了 MoviePilot 的所有过滤能力。
- **索引刷新**：按文档来源隔离缓存；单个工作表失败时保留同来源的旧记录并标明过时及错误。全部失败或结果退化为空时，不覆盖有效缓存。搜索、状态和历史读取不会提交下载或搬运。
- **任务跟踪**：磁力支持十六进制和 Base32 BTIH，ed2k 支持合法文件哈希。下载提交与待搬运状态持久化，失败、任务消失、长时间停滞会显示原因。重复离线任务需核对实际目录和文件身份，不能仅凭“已提交过”视为完成。
- **并发与配置**：同一操作串行协调；历史与待搬运文件使用共享事务锁和原子替换。重新配置会停止旧调度器；无效配置返回失败。配置接口不回显 Cookie，输入框留空保留已有凭据，清除必须显式选择。
- **扫码登录**：按独立会话检查登录状态；“换一张二维码”强制换码。旧页面不能读取或关闭新会话，前端检查请求不会重叠。

## 链接与目录

| 资源 | 行为 |
|---|---|
| 115 分享链接 | 分页读取全部顶层项目后转存到最终目录；完整成功才作为成功结果 |
| `magnet:` / `ed2k://` | 先离线下载到暂存目录，完成并确认文件身份后搬入最终目录 |
| 其它网页链接 | 可查看，不作为下载资源提交 |

默认在电影或电视剧目录下创建 `片名 (年份)` 子目录。磁力/ed2k 搬运使用 MoviePilot 的 `P115Disk` 存储实现；宿主必须具备相应插件、存储配置和目录权限。

同一记录含多条链接时，默认 `link_mode=first`：将它们视为镜像，首条成功后停止，确定失败才回退。只有明确是分卷或多个必要文件时才显式选择 `all`；此时需要全部资源完成，部分成功不等于整体完成。文档没有可靠的镜像/分卷元数据，插件不会自动猜测。

开启获取新版本后，只尝试高于已完成版本质量的候选；升级失败不会回退下载原画质或更低画质。旧历史仍处于未确认提交/搬运状态时，也会阻止相同资源自动重复提交，应先核实已有任务。

**转存或搬入下载目录不等于整理、STRM 生成或媒体库入库。** 后续整理依赖你配置的 MoviePilot/115 插件监控和整理流程。本插件不会因原目录文件消失就标为“已整理”；旧版本缺少明确整理证据的历史状态会降为待确认。

## 设置

| 设置 | 默认值或说明 |
|---|---|
| 启用插件 | 默认关闭；启用后运行定时任务 |
| 电影订阅同步 | 默认开启，但只有插件启用后才执行 |
| 腾讯文档链接 | HTTPS 的 `docs.qq.com/sheet/…` 地址 |
| 腾讯文档 Cookie | 推荐详情页微信扫码；也可手动替换，留空保留 |
| 115 Cookie | 单独填写优先；未单独配置时依次复用 `P115StrmHelper.cookies`、`P115Disk.cookie`、`P115StrgmSub.cookies` |
| 电影下载目录 | `/115-影视/115-downloads/电影` |
| 电视剧下载目录 | `/115-影视/115-downloads/电视剧` |
| 磁力/ed2k 暂存目录 | `/115-影视/115-downloads/磁力链接` |
| 按片名建子目录 | 默认开启 |
| 链接模式 | 默认镜像回退 `first`；明确多份必要文件才选择 `all` |
| 获取新版本 | 默认关闭；开启后，已完成订阅发现更高质量候选才允许再次获取，可能保留多版本 |
| 索引刷新 cron | `0 6 * * *`，北京时间每天 06:00 |
| 订阅同步 cron | `0 21 * * *`，北京时间每天 21:00 |

Cookie 的“已配置”和估算有效期不代表实时鉴权成功；以文档读取或 115 操作的实际返回为准。无待处理离线任务时不请求 115，活动任务按进度检查并在出错时退避。

## 从 0.7.x 升级

1. 备份插件配置及插件数据目录，特别是历史、待搬运任务和订阅状态文件。更新插件源码与 `dist/assets`，然后重新加载插件。
2. **旧索引没有可信的文档来源标记，会作废。** 先在详情页点击“刷新索引”，这是文档只读请求，不会下载或转存。刷新完成后确认记录数、失败工作表和过时提示，再重新搜索。
3. 检查 Cookie、暂存/最终目录、MoviePilot 整理监控和依赖是否就绪。旧电影订阅去重记录会保留；不会为验证升级而自动重下已完成影片。
4. 默认使用镜像回退，获取新版本默认关闭。使用外部过滤组的订阅会提示无法可靠评估，需要你检查该订阅的规则，不会自动绕过。
5. 查看已有未完成任务与历史提示。删除/清空历史只删除展示记录，下载及自动搬运继续；“停止自动搬运”单独取消跟踪，不取消 115 中的下载，也不删除文件。失败或失踪任务需要核对后显式重试。

## 需要人工判断的情况

- 腾讯文档接口、表头或链接结构改变时，部分表可能无法解析；保留旧索引不代表这些记录仍有效，应关注过时提示。
- 分享转存超时或断线后，115 可能已经接收部分请求。此类结果保持未确认，避免盲目重复发送；先在网盘核对目标目录和记录，再决定后续操作。
- 离线任务在其它目录、原文件已被移动/删除、存储权限或搬运失败时，不会猜测认领其它同名文件。长期未落盘、停滞、连续搬运失败需要人工处理。
- 历史最多展示最近 200 条。清空历史不会清除活动任务，但会减少用于人工核对的上下文，建议活动任务完成后再清理。
- 本次自动化验证使用合成文档、虚构资源和假服务，没有执行真实下载、转存或入库验收；它验证已覆盖的逻辑和接口契约，不能保证外部平台永远不变。

## 运行依赖

MoviePilot V3、Python 3.12 及以上。MoviePilot 从 `pyproject.toml` 安装锁定版本：`p115client==0.0.9.6.5.1`、`python-concurrenttools==0.1.8`。不要随意升级 `python-concurrenttools`，新版移除了当前依赖所需接口。

扫码另需容器中可用的 `playwright` 和 Chromium；当前浏览器实现检测 `/moviepilot/.cloakbrowser/*/chrome-linux/chrome`，优先使用已知宿主路径。缺少浏览器时会明确报错，可改为手动配置腾讯文档 Cookie。文档读取自身仅使用 Python 标准库。

## 纯模拟验证与前端构建

建议在独立 Python 3.12 环境中从仓库根目录执行。测试不需要任何 SSH、MoviePilot、115 或 GitHub 凭据，也不会提交真实资源。后端编排测试主动阻断网络，外部服务均为假实现；FastAPI/TestClient 和调度器测试使用真实框架、合成配置与内存 HTTP 请求。

```bash
python -m pip install 'fastapi==0.115.12' 'httpx==0.28.1' 'APScheduler==3.11.0'
python -m unittest discover -s tests -p 'test_doc115subscribe_*.py' -v
cd plugins.v3/doc115subscribe/ui
npm ci --ignore-scripts
npm run build
cd ../../..
node --test tests/test_doc115subscribe_frontend.mjs
```

Python 测试覆盖解析、严格匹配、索引切换、分页、持久化并发、失败恢复、调度器、配置及扫码；Node 测试覆盖结果身份、旧搜索响应、重复点击、凭据显示和扫码请求。缺少测试框架依赖时，仅相关框架测试会跳过；CI 会安装这些依赖后运行。安装 pip/npm 依赖会访问软件包镜像，测试本身不连接真实资源服务。

前端源码在 `ui/src/components/`，运行期 MoviePilot 加载的是 `dist/assets/remoteEntry.js`。修改源码后构建，将 `ui/dist/assets/` 的完整文件集同步到插件的 `dist/assets/`，清理旧哈希文件，不手改编译产物。独立 CI `doc115subscribe.yml` 运行以上模拟验证，并检查构建产物与已提交 dist 的文件集合和内容一致。
