# MoviePilot-Plugins

由 [zoom521241](https://github.com/zoom521241) 维护的 MoviePilot V3 插件仓库，主要收录 115 网盘与文档订阅相关插件。

## 插件

| 插件 | 版本 | 说明 |
| --- | --- | --- |
| 115文档订阅与查询 | 0.12.2 | 读腾讯文档追更表，按 MP 订阅自动转存到 115；支持跨表搜索、一键转存、磁力/ed2k 离线 |
| 115网盘订阅追更 | 1.5.12 | 结合 MP 订阅搜索 115 资源，转存缺失的电影与剧集 |
| 115网盘STRM助手 | 2.8.74.9 | 整理 115 资源到媒体库目录并生成 `.strm`，供 Emby / Jellyfin 直链播放 |
| 115网盘储存 | 3.0.5 | 作为 MP 存储模块接入 115 网盘 |
| 金山文档订阅添加 | 1.2.0 | 每日扫描金山文档追剧表，把在播新剧加入 MP 订阅 |
| Emby媒体库封面生成 | 1.0.2 | 为 Emby / Jellyfin 媒体库生成动态或静态封面 |
| 夸克网盘搬家 | 0.1.0 | 把夸克网盘指定目录中的影片搬迁到 115 |

## 安装

在 MoviePilot 插件市场添加本仓库地址（插件通过 Release 安装，每个插件仅保留最新版本）：

```text
https://github.com/zoom521241/MoviePilot-Plugins
```
