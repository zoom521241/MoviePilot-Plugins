# MoviePilot-Plugins

个人维护的 MoviePilot 插件仓库，包含基于实际 V3 环境验证的 115 插件兼容修复。

| 插件 | 版本 | 说明 |
| --- | --- | --- |
| 115网盘STRM助手 | 2.8.74.2 | 修复 V3 整理重复入队、停止后继续执行；补齐安装所需模块及依赖包 |
| 115网盘储存 | 3.0.3 | 修复并发限流等待不断增长、移动后重命名及文件状态核验；要求 MoviePilot V3 |
| 115网盘订阅追更 | 1.5.4 | 保留原有版本 |
| Emby媒体库封面生成 | 1.0.2 | 后台合并处理入库事件，背景图失败回退海报；要求 MoviePilot V3 |

在 MoviePilot 插件市场添加此仓库地址：

```text
https://github.com/zoom521241/MoviePilot-Plugins
```

当前沿用 `package.v2.json` 和 `plugins.v2/` 布局。MoviePilot V3 可通过兼容索引发现这些插件；储存插件声明 `system_version >=3.0.0`，使用 V3 SDK。STRM 助手保留旧版本分支，本次验证在 V3 完成。

## 本次修复

STRM 助手原有异步整理接管绕过 V3 的持久化任务结算，会让恢复线程重复提交同一任务。检测到 V3 整理链时，现在交由宿主原生流程执行，并继续使用插件发现文件和生成 STRM。停止队列后不再提交剩余批次。

储存插件在云盘移动成功后使用稳定的文件 ID 完成重命名，避免依赖尚未更新的路径查询。目录 ID 统一按整数处理，防止将非根目录误判为根目录；严格存在性查询读取远端状态，网络错误仍按未知状态处理。

3.0.3 将限流时间采样移入锁内，修复并发时等待从 2 秒增长为 4、8、16 秒等的问题，保留原有调用频率限制。回归测试用真实线程和虚拟时钟验证等待时间与配额。

封面插件将入库事件交给可停止的后台队列，同一批次、同一媒体库合并生成。Emby 无法下载远程背景图时，回退同一媒体项的海报；停止任务后取消待处理事件和后续上传。原有配置和样式保持兼容。

V3 环境已实测复制一个视频到监控目录，自动整理完成移动、重命名及 STRM 生成；另一个先前失败的视频重试成功。直接查询云盘确认文件大小、SHA1 和目标目录正确，整理及重试队列正常收口。回归测试可运行：

```sh
python -m unittest discover -s tests -v
```

## 更新与持久化

拉取 Docker 新镜像不会直接修改正在运行的插件。重建容器时应保留原 `/config` 挂载；新版宿主的恢复流程和接口兼容性仍需确认。插件升级或重装会替换代码，应从包含本次修复的来源安装。

仓库推送不会自动切换现有安装的插件来源。在 MoviePilot V3 的插件来源选项中明确选择本仓库，刷新市场后安装对应版本；仅覆盖运行目录不能保证容器重建后仍使用修复版。保留 `/config` 挂载和本仓库来源绑定，可从这里重新安装。未来宿主或 115 接口变化仍可能需要新的兼容补丁。
